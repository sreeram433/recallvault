# In-app consent language

## First run

> Start a local library. It lives in this browser. ReelVault never asks for your Instagram password and never imports your Instagram Saved tab by itself.

## Preview fetch

> Fetch public preview? This reads publicly available page titles and images. It does not log into Instagram. If the site blocks us, you can still save the link.

## AI suggestions

> Suggest tags with optional AI? Suggestions are shown for you to accept or ignore. Nothing is filed automatically.

> Include my note in this AI request? Leave this off unless you want the model to read the note you just typed.

## Dead link

> Mark the original unavailable? We will keep your notes and metadata. We cannot restore the Instagram post.

## Export

> This file is your metadata only. Original Instagram media is not included.

## Delete

> Erase this vault permanently? This deletes every item, note, tag, reminder, and audit log stored in this browser. Export first if you want a copy.

## Extension

> ReelVault only receives this tab’s URL after you click Save.
