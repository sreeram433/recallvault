# MVP implementation plan (weekly)

## Week 1 — Sign-in and personal library

Local profile, IndexedDB schema, default collections, landing privacy copy.

## Week 2 — Capture

Paste URL, share target, source detection, duplicate warning, inbox.

## Week 3 — Notes, tags, collections

Item editor, multi-collection, tag rename/delete, Needs Review.

## Week 4 — Search

MiniSearch + natural-language date/type/creator parser, filters, sort, match highlights, pagination.

## Week 5 — Export and deletion

CSV/JSON/Markdown, Instagram export URL ingest, audit log, erase.

## Week 6 — Extension

MV3 popup + shortcut. No content script.

## Week 7 — Rediscover

Weekly five, stale dashboard, reminders, dead-link marker.

## Week 8 — Optional AI

SpaceXAI suggest route, consent flags, embedding column reserved.

This repository implements weeks 1–8 as a local-first starter. Cloud sync SQL is included but not wired as a required path.
